# Case Study: <Project Title>

## Problem Statment
The student (or team) is expected to design and implement a Graph Convolutional Network (GCN) to detect malicious
IP addresses in network traffic. They will construct graphs from the CICIDS 2017 dataset, train the GCN, and compare
its performance against traditional machine learning baselines such as Logistic Regression and Random Forest. The
challenge lies in building reproducible pipelines that leverage graph structures for intrusion detection and evaluating
whether graph-based approaches provide measurable improvements.
